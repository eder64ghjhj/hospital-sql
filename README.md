# 🏥 Sistema de Hospital — SQL

Projeto de banco de dados relacional modelando um sistema hospitalar completo, desenvolvido durante o programa PROA. Inclui diagrama entidade-relacionamento e scripts SQL organizados em partes evolutivas.

## 📊 Diagrama ER

O projeto inclui diagrama entidade-relacionamento completo modelando as entidades do sistema hospitalar.

## 🗄️ Estrutura do Banco

- Cadastro de pacientes
- Cadastro de médicos e especialidades
- Registro de consultas e internações
- Controle de quartos e enfermeiros
- Relacionamentos entre entidades

## 🛠️ Tecnologias Utilizadas

- MySQL
- SQL (DDL e DML)
- Draw.io (diagrama ER)
